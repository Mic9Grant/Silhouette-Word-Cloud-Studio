# User guide

1. Open index.html. Choose a built-in shape, select Lettering to enter the letters to fill, or select Upload and choose a silhouette image.
2. For uploaded images, choose automatic detection, non-transparent pixels, dark areas or light areas. Adjust Threshold if the outline is not recognized.
3. Under Words, paste free text or select Weighted list. The sample weighted list demonstrates the accepted format. Repeated or more heavily weighted words become larger.
4. Set maximum unique words, minimum letters, case, and excluded words.
5. Under Color and style, select a typeface and palette. Import local TTF, OTF, WOFF or WOFF2 files, or add a Google Font by name while connected.
6. Choose a transparent or solid background, image overlay, tint or outline.
7. Under Layout, adjust font sizes, direction, spacing, density, edge handling and detail.
8. Select Generate, or New layout for another arrangement. Export PNG or SVG using the export controls.

## Troubleshooting

If few words fit, lower word sizes or spacing, simplify the silhouette, or try another density setting. If nothing appears, review the image detection mode and threshold and check that the text contains usable words after filtering. If an export fails, reduce its size. Remote fonts may be unavailable offline; choose an embedded font. SVG appearance can vary between viewers because of font loading and raster layers.
